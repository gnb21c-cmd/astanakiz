# 아스타나키즈 입장 데스크 — 다른 프로젝트와 공유할 내용

> 다른 프로젝트(보고 시스템 `gnb21c-cmd/report`, 아스타나 앱 `gnb21c-cmd/astana` 등) 세션은 이 문서만 읽으면 된다.
> 이 저장소에서 기능을 바꾸면 이 문서도 같이 고친다. 자세한 규칙은 `docs/OPERATION.md`, 연동은 `docs/NAVER.md` · `docs/AMANO.md` · `docs/INTEGRATION.md`.
> `gnb21c-cmd/younggu`(영구)는 별도 사업이라 공유하지 않는다.

기준: **ver.1.36** (2026-10-09)

## 1. 무엇인가
- 아스타나키즈(키즈존) **POS PC 한 대**에서 쓰는 근무자용 데스크 앱 (Windows · Electron, 1024×768 한 화면)
- 네이버 예약자 입장 · 현장 판매(결제는 OKPOS) · 열쇠 45개 관리 · 아마노 주차 할인 등록을 한 화면에서 처리
- 손님용 앱이 아니다. 문자 · 알림을 보내지 않는다. API 없이 **네이버 · 아마노 웹 화면을 숨은 창에서 대신 조작**한다
- 설치 파일: GitHub Releases `v1.X` (main 에 올리면 GitHub Actions 가 만듦) · 직원 메뉴얼 PDF 같이 올라감
- 체험판(설치 없이 화면만): `prototype/desk.html` → https://claude.ai/artifact/XkfdV6BDaG7AEMzRqNzSZH

## 3. 데이터 — POS PC 에 남는 것 (보고 시스템이 가져다 쓸 수 있음)
폴더: `%APPDATA%\아스타나키즈 입장 데스크\`

**`desk-state\YYYY-MM-DD.json`** — 그날 입장 기록 (켜고 끄거나 재설치해도 남음)
```jsonc
{
  "v": 2,
  "b": [  // 데스크에서 입장 처리한 네이버 예약
    { "no": "1368155282", "name": "허정은", "phone": "01046740736", "slot": 840,   // slot = 예약 시각(분, 840 = 14:00)
      "qty": 1, "status": "완료", "keys": [12], "enteredAt": 836, "outAt": 950,      // 입장 · 퇴장 시각(분)
      "prevDone": 8, "visitNo": 9, "visitEnd": 9,                                    // 네이버 '완료 n' (예약 이용완료 횟수)
      "proxy": false, "visitor": "",                                                 // 대리예약 · 방문자 "이름(전화번호)"
      "keyUse": { "12": 110 }, "chainHead": null, "overPaid": { "amount": 5000 },    // 열쇠별 이용시간(분) · 연속/추가 예약 대표 · 초과요금
      "keysTaken": [12], "bulkOut": false,                                           // 받은 열쇠 번호(반납해도 남음) · 일괄 반납으로 돌려받음 (1.32~)
      "naverSlot": 840 }                                                             // 네이버 원래 예약 시각(분) — slot 과 다르면 데스크에서 옮긴 예약 (1.33~)
  ],
  "w": [  // 현장 구매
    { "id": "w3", "phone": "01012345678", "keys": [20, 21], "keysTaken": [20, 21], "qty": 2, "enteredAt": 760, "slot": 750, "posNo": "POS-0001", "outAt": null }
  ],
  "x": ["1368411002"],  // '기록 삭제'(시험으로 잡힌 손님) — 판매수 · 통계에서 뺄 예약번호
  "ig": [],             // 추가 예약을 '그대로 두기'로 한 예약번호
  "mv": [["1368155282", 900]], // 데스크에서 시간을 옮긴 예약 [예약번호, 옮긴 시각(분)] (1.33~)
  "g": { "at": 1050, "keys": 19, "rest": 2 }  // 골든벨: 이 시각부터 그날 모든 손님 무제한 (1.36~, 없으면 null)
}
```
- 파일은 지우지 않음 (데스크 입장권 목록에서 2주 전까지 열쇠 번호 · 전화번호를 찾아봄). `keys` 는 지금 가진 열쇠(반납하면 빔), 어떤 열쇠를 썼는지는 `keysTaken`
- **그날 입장권 판매수** = 네이버 이용완료 장수(네이버 칸 숫자) − `x` 의 장수 + 현장 `qty` 합
- `w` 에 `extra: true` 인 줄 = 열쇠 창 [+1타임](입장권을 열쇠 수만큼 더 산 것 · `of` = 원래 손님 · `keys` 비어 있음) — 판매수에 넣음 (1.36~)
- 현장 `slot` = 입장 타임(접수 시각의 바로 앞 30분 칸, 근무자가 ◀ ▶ 로 바꿀 수 있음)
- `settings.json` — 프린터 · 아마노 주소(비밀번호는 Windows 암호화) · 성수기 기간 · 수량 자동조절 설정 · 톡톡 상담 목록 주소(`talkUrls`) · 현금통 단자(`drawerPin`)
- 수량 자동조절 기록 · 예약 속도 · 과거 실제 수는 앱 안 저장소(localStorage)에 있음 (`astanakiz-caplog-날짜`, `astanakiz-capseen-날짜`, `astanakiz-caphist` = 요일 종류 → 시각 → 최근 40번 `{ d, used, walk }`)

## 4. 외부 연동
| 대상 | 방식 |
|---|---|
| 네이버 스마트플레이스 예약 | 숨은 창에서 예약현황(일간) 읽기(09:50부터 매시 20 · 50분, 대리예약 방문자 · 입금대기 포함) · 이용완료 2단계 누르기 · 회차당 수량 바꾸기 · 입금대기 예약 자동 취소(지금 ~ 2시간 안). 로그인은 근무자가 직접(비밀번호 저장 안 함) |
| 네이버 톡톡 상담 | 계정 2개(아스타나키즈 · 카페아스타나)를 숨은 창에 열어 상담 목록 줄의 붉은 원(안 읽은 메시지 수)을 20초마다 더해 버튼에 표시 · 버튼 → 상담 창, X → 데스크로. 로그인은 예약과 같은 네이버 아이디 · 주소는 POS PC 에만 |
| 아마노 주차 | 숨은 창 2개(검색용 · 뒤에서 할인 등록용). 아이디 · 비밀번호는 POS PC 에만 암호화 저장 |
| 현금통 | 데스크 맨 위 [환전 오픈] → 영수증 프린터로 ESC/POS 열기 명령(ESC p) — POS 프로그램이 꺼져 있어도 |
| OKPOS | 결제는 POS 에서. 데스크는 POS 창을 앞으로 띄우고(최소화돼 있으면 복원), POS 를 최소화하면 데스크로 돌아옴 |
| 영수증 프린터 OKPOS OK-50 | COM 포트 ESC/POS 직접 출력(42칸), 양식은 운영 설정에서 고침 |

## 5. 정한 규칙 (요약 — 자세히는 `docs/OPERATION.md`)
- 열쇠 45 = 기본 40 + 유동 5 · 4인석 39
- 이용시간: 성수기(평일 · 휴일)와 비수기 휴일 = 17:30 입장까지 1시간 50분, 18:00 입장부터 무제한 · 비수기 평일 = 무제한
- 초과요금: 1:50:01부터, 2:00 정각 5,000원, 10분마다 5,000원 × 열쇠 수 (POS 에서 결제)
- 연속예약: 같은 이름 + 전화번호, 2시간 이내 간격 → 처음 입장 때 함께 이용완료, 끝 = 마지막 예약 + 1:50
- 같은 시간 나눠 한 예약: 한 번에 입장, 열쇠 합친 장수
- 추가 예약(이용 중 뒤 타임 예약): 딱 2시간 뒤 자동 연장 · 가까우면 선택 · 2:30 이상이면 당겨서 이어서 / 그대로 두기
- 이용완료 횟수 = 네이버 '완료 n'(같은 아이디의 **예약 건수**, 장수 무관). 문구는 '방문'이 아니라 "N번째 예약완료" · "네이버 예약 N번 이용완료". 10번마다 2만원 사은권
- 네이버 판매 수량 자동조절(성수기 · 비수기 주말/휴일만): 어느 시각에도 안에 있는 손님이 **상한 43**을 넘지 않게, 목표 42, 한 타임 최대 13, 10분마다. **좌석(열쇠) 기준**(안의 손님은 열쇠 반납 시각까지) · 비인기 먼 타임은 예상만큼(같은 요일 지난주 70% · 3주 평균 10% · 추세 10% · 오늘 10%, 과거 없으면 지금 예약 수준 90% · 오늘 추세 10%) (1.34~ · 1.35)

## 6. 다른 프로젝트와의 관계
- **아스타나 앱(`gnb21c-cmd/astana`)**: 회원 · 결제 · 마일리지를 공유하지 않는다(제로베이스). 가져온 것은 **브랜드 로고**(`packages/ui/src/assets/logo.png` → 설치 아이콘 `apps/desk/build/icon.ico`)뿐
- **보고 시스템(`gnb21c-cmd/report`)**: 3장의 `desk-state` 파일로 그날 네이버 입장 · 현장 구매 · 입장 타임 · 초과요금을 읽을 수 있다. `x` 의 예약번호는 시험 기록이니 빼고 셀 것
- 공유 방법: 다른 세션에서 "gnb21c-cmd/astanakiz 의 docs/SHARE.md 를 읽어" 라고 하면 된다

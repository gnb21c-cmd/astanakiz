# 네이버 예약 연동

API는 쓰지 않는다. 앱이 맨 뒤에 **네이버 예약관리(스마트플레이스 파트너센터) 예약현황** 창을 열어 두고, 화면을 읽고 버튼을 대신 누른다.

## 창 배치 (모니터 한 대)
```
맨 앞   입장 데스크
가운데  POS (OKPOS Program)
맨 뒤   아마노 할인등록 · 네이버 예약관리 (입장 데스크 앱이 열어 둔 창)
```

## 처음 한 번 (POS PC)
1. 운영 설정 → 아마노 · POS → **네이버 화면 보기 (로그인)** → 네이버 로그인 (2단계 인증이 있으면 그대로)
2. 예약관리 → **예약현황** 화면까지 들어감 → **지금 화면을 시작 화면으로**
3. 그 뒤로는 로그인 상태가 이 PC 앱에 계속 남는다 (네이버 비밀번호는 앱에 저장하지 않음)

## 데스크가 하는 일
| 언제 | 네이버 화면에서 (자동) | 데스크에 |
|---|---|---|
| 앱 켤 때 · 새로고침 · 날짜 ← → · 3분마다(오늘) | 그 날짜로 이동 → 입장권 칸마다 확정·이용완료를 열어 예약자 카드를 읽음 | 시간별 확정/잔여, 예약자 명단(예약자 · 전화번호 · 이용일시 · 수량 · 결제상태 · 완료 n · 취소 n) |
| 네이버 예약자 **등록 완료** | 그 예약 칸 → 카드의 **이용완료** → 확인 → 완료로 바뀐 것을 다시 읽어 확인 | 확인되면 열쇠 등록, 방문 회차 = 미입장 때 읽은 완료 n + 1 |
| 네이버가 안 될 때 | — | "네이버 이용완료 실패" + **네이버 없이 열쇠만 등록** (나중에 네이버에서 직접 이용완료) |

- 상품은 이름에 **입장권**이 들어간 것만 (단체 · 열쇠분실 상품은 뺌)
- 오늘의 열쇠·입장 기록은 이 PC에 저장 → 앱을 껐다 켜도 열쇠판 유지

## 코드와 시험
| 파일 | 내용 |
|---|---|
| `apps/desk/src/naver-driver.js` | 예약현황 화면 안에서 날짜·칸·카드 읽기, 칸 열기, 이용완료 누르기 |
| `apps/desk/src/naver-sync.js` | 날짜 이동 → 하루 예약 모으기, 이용완료 → 완료 확인 |
| `apps/desk/mock/naver.html` | 캡처를 본뜬 **시험용 가짜 예약현황 화면** |
| `apps/desk/test/naver-sync.test.js` · `desk-naver.test.js` | 하루 예약 읽기, 날짜 이동, 이용완료, 로그인 풀림, 데스크↔네이버 연결 |

## 남은 일
- **실제 예약현황 화면 저장 파일**(Ctrl+S, 웹 페이지 전체, 오른쪽에 예약자 카드가 열린 상태)로 `naver-driver.js` 의 칸·카드 찾는 법을 실제 구조에 맞추기 — 지금은 캡처를 본뜬 구조
- 이용완료를 누르면 뜨는 확인 창 모양 확인
- 가능하면 하루 예약이 표로 나오는 '예약 목록' 화면도 저장 → 칸을 하나씩 열지 않고 한 번에 읽을 수 있음 (더 빠름)

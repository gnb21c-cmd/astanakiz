재방문 이벤트 근무 안내

키즈존 입구 · 식사 시간이나 빈 시간에 지원 오신 분도 이 한 장이면 됩니다
기간  월  일 ~  월  일
사은품 수제돈까스 · 기한 20일

1이벤트 한눈에

취지
네이버 예약 손님이 다시 오시게 하는 이벤트예요. 다시 올 때마다 선물이 이어져 단골이 되도록 합니다.
규칙
방문한 날부터 20일 안(그날 포함)에 다시 오면 수제돈까스 무료 → 다시 온 날부터 또 20일, 계속 이어져요. 20일을 넘기면 그날부터 새로 시작해요. 기한은 이벤트 종료일을 넘지 않아요.
대상
네이버 예약으로 입장한 손님만, 같은 네이버 아이디로 한 예약끼리 이어서 셉니다. 현장 구매(예약 없이) 손님은 대상이 아니에요. 같은 날 예약이 여러 건이어도 방문은 하루 한 번.
마일리지
이벤트 동안 네이버 이용완료 횟수 · 10번째 2만원 사은권은 멈춰요 (카드에 횟수가 안 보이는 이유). 이벤트가 끝나면 이벤트 때 방문은 빼고 원래대로 이어서 셉니다.
자동
손님 분류 · 기한 계산 · 입장권 문구 · 방문 기록은 데스크가 모두 알아서 해요. 근무자는 평소처럼 입장 처리만 하면 됩니다.

2근무 순서 — 평소와 똑같아요

  1. 왼쪽 시간 칸 → 손님 예약자 카드를 누르고 이름 · 전화번호를 확인
  2. 설문 번호가 나오면 손님께 여쭤 번호 먼저 누르기
  3. 열쇠 번호를 수량만큼 고르기
  4. [등록 완료] → 네이버 이용완료와 입장권 출력은 자동
  5. 열쇠 + 입장권을 드리며 카드 표시대로 한마디 (오른쪽 표). 성공이면 입장권 아래 쿠폰을 잘라 드려요

화면 아래 알림에 "이벤트 성공 — 수제돈까스 드리세요"가 뜨면 쿠폰을 꼭 챙겨 드리세요.

3카드 표시 보는 법

카드 글자뜻 · 입장권 → 손님께 한마디
이벤트 시작
(흰 글씨)		이벤트 첫 방문 (또는 20일이 지나 새로 시작) · 입장권 "○월 ○일(포함)까지 다시 오시면 수제돈까스 무료 증정!"→ "이 날짜까지 다시 오시면 수제돈까스 드려요"
수제돈까스 쿠폰 지급하세요기한 안에 다시 옴 = 성공 · 입장권 "재방문 이벤트 성공!" + 쿠폰 + 다음 기한→ "축하드려요, 쿠폰 드릴게요. ○월 ○일까지 또 오시면 또 드려요"
오늘 이미 방문같은 날 두 번째 예약 · 기한 그대로, 쿠폰 없음→ "쿠폰은 하루 한 번이에요"
이벤트 켜기 전 입장이벤트를 켜기 전에 이미 처리된 손님 → 할 일 없음

다음 기한 날짜는 입장권에 찍히고, 카드 글자 위에 마우스를 올려도 보여요.

4꼭 알아 둘 것

  • 같은 네이버 아이디로 계속 예약하셔야 이어져요. 가족의 다른 아이디로 예약하면 그 아이디로 새로 시작해요. 대리예약도 예약한 아이디 기준.
  • 이벤트 기간에는 2만원 사은권이 나가지 않아요. 손님이 물으시면 "이벤트 끝나면 이어서 쌓여요(없어지지 않아요)".
  • 입장권이 안 나와도 방문 기록은 [등록 완료] 때 이미 저장돼요. 종이 · 프린터를 확인하고 안 되면 키즈존 책임자에게 (운영 설정 → 프린터 [테스트 출력]).
  • 방문 기록은 POS PC 바탕화면 '아스타나키즈-이벤트' 폴더에 자동 저장돼요. 손대거나 지우지 마세요. 손님 기록이 궁금하면 운영 설정 → 방문 이벤트 → 손님 찾기(이름 · 전화 뒷번호).
  • 진짜 쿠폰은 글자만 있지 않고 위 · 아래에 가로 두 줄 + 아주 작은 글씨 띠(ASTANAKIDS·날짜)가 붙어 나와요 (가짜 방지 — 날짜가 그날인지). 바리스타는 이 무늬가 있는 쿠폰만 받아요.
  • 쿠폰 사용:   (매장 안내에 맞춰 적어 두세요)

5전화로 이벤트를 물어보시면

"지금 재방문 이벤트 중이에요. 네이버로 예약하고 오시면 입장권에 날짜를 찍어 드리는데, 그 날짜까지(방문일부터 20일 안) 다시 오시면 수제돈까스를 무료로 드려요. 다시 오신 날부터 또 20일 안에 오시면 또 드리고요. 같은 네이버 아이디로 계속 예약해 주시면 돼요. 이벤트는  월  일까지예요."

현장에서 사도 되나요? — 이벤트는 네이버 예약 손님만이에요. 네이버로 예약해 주세요.

마일리지(2만원 사은권)는요? — 이벤트 동안 잠시 멈추고, 끝나면 이어서 쌓여요.

하루에 두 번 오면요? — 쿠폰은 하루 한 번이에요.

날짜를 넘기면요? — 그날이 다시 첫 방문이 되어 새로 20일이 시작돼요.

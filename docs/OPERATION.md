# 아스타나키즈 운영 방식 정리

## 1. 지금 운영 방식

### [방법1] 네이버 예약 구매 → 매장 입장
1. 고객이 네이버에서 "아스타나키즈"를 검색해 스마트플레이스에서 날짜·시간을 골라 입장권을 구매한다.
2. 매장에 오면 근무자가 이름을 묻고, 네이버 구매자 목록에서 이름을 찾는다.
3. 예약 시간 5분 전부터 입장시키고, 현장에서 **이용완료** 버튼을 누른다.
4. 입장 처리 때 고객별 메모장에 **지급한 키 번호를 일일이 입력**하고 완료를 누른다. → 손이 많이 간다.
5. 키 반납이 늦어지면 그 키 번호를 받은 고객을 해당 시간대에서 **일일이 찾아 전화**한다.

### [방법2] 현장 구매 → 입장
- 현장에서도 입장권을 사서 입장할 수 있다.
- **예약자가 우선**이다. 만석 기준으로 자리가 남을 때만 현장 판매·입장을 한다.

## 2. 불편한 점
근무자가 **네이버 예약창 · POS · 주차 웹 · 열쇠 기록 웹**을 오가며 맞춰 보고 판단해야 한다.
- 이름으로 구매자 목록을 찾는 시간
- 키 번호를 메모장에 손으로 적는 일
- 반납이 늦은 키의 주인을 찾아 전화하는 일
- 예약 손님 자리를 남기고 현장에서 몇 장 팔 수 있는지 매번 판단하는 일
- 주차 웹에 차량번호를 따로 넣는 일

## 3. 새로 만드는 방향 (제로베이스)
- 아스타나 앱의 것은 **아무것도 가져오지 않는다.**
  - 별빛(충전 결제), 고객·관리자·근무자·대표자 앱 나눔, 요금·열쇠·예약 규칙 모두 처음부터 다시 정한다.
- 하나로 합칠 일
  1. 네이버 예약자 입장·퇴장 통제
  2. 현장 결제 (POS 연계)
  3. 열쇠 관리
  4. 주차 관리 웹 입력
- 근무자는 **POS PC 화면(1024×768) 한 장**에서만 일한다.

## 4. 쓰는 사람 (새로 정의)
| 누구 | 무엇으로 | 하는 일 |
|---|---|---|
| 근무자 | POS PC의 **입장 데스크** 한 화면 | 네이버 예약자 입장, 현장 결제, 열쇠 지급·반납, 주차 등록 |
| 손님 | **앱 없음.** 네이버로 예약하거나 현장에서 구매 | — (문자 안내도 보내지 않음) |
| 사장님 | 따로 앱을 만들지 않음. 데스크의 운영 설정에서 성수기 기간을 정함 | 성수기 기간 설정 |

이 시스템은 손님용 앱이 아니다. **근무자의 편리성**만 높인다.

## 5. 정한 규칙
| 규칙 | 내용 |
|---|---|
| 열쇠 | 45개 = **기본 40개 + 유동 5개** |
| 좌석 | 내부 4인석(입식·좌식) 39석 |
| 유동 열쇠 | 이론상 40석이 필요하지만 실제로 40석이 다 찬 적은 없음(카페 쪽으로 나가는 손님 등). 그래서 기본 40개를 넘으면 유동 5개를 **안에 빈 좌석을 보고** 쓴다 |
| 이용시간 — 성수기 | 평일·휴일 구분 없이 **17:30 입장까지 1시간 50분**, **18:00 입장부터 무제한** |
| 이용시간 — 비수기 | **평일은 항상 무제한**, 휴일(토·일·공휴일)은 성수기와 같음 |
| 성수기 기간 | 운영 설정에서 기간을 정함 (예: 여름방학·겨울방학) |
| 입장 | 예약 시간 5분 전부터 (지금 방식 그대로), 입장은 30분 단위 |
| 열쇠판 색 | 빈 열쇠 회색 · 예약 입장시간부터 1시간 50분까지 검정(숫자·이름) · 2시간까지 분홍 · 2시간 넘으면 빨강 |
| 현장 결제 | 데스크에서 결제하지 않음. "결제하기"로 POS 창 전환 → 결제 → POS 최소화 → "결제 완료"로 열쇠 등록 |
| 주차 | 아마노코리아 할인등록 웹 화면을 데스크가 대신 조작(동기화). 할인유형 3시간 · 5시간 · 15시간 |
| 반납 지연 | 문자·전화 안내 없음(업무용 화면). 반납 시각이 지나면 열쇠 팝업에 초과 경과시간과 초과요금이 실시간으로 올라감 |
| 방문 사은권 | **10회 방문마다 2만원 사은권**(명함식 카드). 근무자 화면은 실제 회차(11번째), 영수증은 10회 단위로 다시 셈(11회차 → 1번째). 10·20·30번째에 사은권 증정 알림 |
| 초과요금 | 예약 입장시간부터 **1:50:00까지 페널티 없음**, **1:50:01부터 카운트업**. **2:00:00 정각 5,000원**, **2:10:00 정각 10,000원** … 10분이 꽉 찰 때마다 5,000원씩 오름. **열쇠 수만큼 곱함** (열쇠 2개면 2:00:00에 10,000원). 무제한 손님은 없음 |

### 아직 임시 값
| 규칙 | 체험판 임시 값 | 정할 것 |
|---|---|---|
| 열쇠 지급 단위 | 입장권 1장 = 열쇠 1개 | 네이버 입장권 1장이 한 팀(4인석 1개)인지 |
| 현장 입장권 가격 | 16,000원 | POS에 등록된 상품·가격을 그대로 씀 |
| 공휴일 | 체험판은 몇 날짜만 넣어 둠 | 공휴일 달력 자료로 자동 |

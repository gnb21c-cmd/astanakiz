# 아마노 주차등록 화면 동기화

API는 쓰지 않는다. 3번 모니터에 열려 있는 **아마노코리아 할인등록 웹 화면**을 데스크 앱이 대신 조작한다.
근무자가 데스크에서 입력하고 누르면, 아마노 화면에서도 같은 칸에 같은 값이 들어가고 같은 버튼이 눌린다.
아마노 화면에 나온 결과(조회 목록·주차시간·할인내역)는 다시 읽어 와 데스크에 보여 준다.
3번 모니터의 아마노 화면은 그대로 보이므로, 근무자가 눈으로 함께 확인할 수 있다.

## 동작 맞추기
| 데스크에서 | 아마노 화면에서 (자동) | 데스크로 읽어 오는 것 |
|---|---|---|
| 입차일 (기본 전날 — 새벽 손님 때문) | 입차일 칸에 같은 날짜 | — |
| 차량번호 입력 → 검색 | 차량번호 칸에 입력 → **검색** 버튼 | 조회 목록: 입차ID · 차량번호(건수) · 입차시간 |
| 목록에서 차량 선택 | 같은 줄 클릭 | 차량번호 · 입차시간 · **주차시간** · 할인내역 |
| 할인 버튼 (3시간 · 5시간 · 15~18시간) | 같은 이름의 **할인유형** 버튼 | 할인내역: 할인값 · 등록자 · 등록시간 |
| 할인내역 삭제 | 그 줄의 **삭제** 버튼 | 바뀐 할인내역 |

## 버튼 위치를 찾는 방법
| 방법 | 내용 | 판단 |
|---|---|---|
| **A. 웹페이지 안의 칸·버튼 이름으로 찾기 (추천)** | 아마노 화면은 웹페이지라서, 화면 좌표가 아니라 페이지 안의 "차량번호 칸", "검색 버튼", "5시간할인 버튼"을 이름으로 찾아 넣고 누른다. 결과 표도 글자 그대로 읽는다 | 창을 옮기거나 크기·해상도가 바뀌어도 정확. 결과를 읽을 수 있음 |
| B. 화면 좌표 기억해 마우스로 누르기 | 처음에 버튼 위치를 한 번씩 눌러 기억시키고, 마우스·키보드를 대신 움직임 | 창이 움직이거나 스크롤되면 틀어짐. 결과를 읽으려면 화면 글자 인식이 필요. 비상용 |

A를 쓰는 방법 두 가지:
1. **데스크 앱이 아마노 화면을 직접 띄움**: 데스크 앱(Windows 프로그램)이 3번 모니터에 아마노 페이지 창을 열어 둔다. 보기에는 지금과 같은 웹 화면이고, 데스크 앱이 그 안을 조작한다. (추천 — 가장 안정적)
2. **지금 쓰는 Edge 창에 연결**: Edge를 "원격 조작 허용" 옵션으로 실행해 두면 데스크 앱이 열린 아마노 탭에 붙어서 조작한다. Edge 바로가기만 바꾸면 됨.

## 주의
- 아마노 로그인이 풀리면 데스크에 "아마노 다시 로그인" 표시를 띄운다. 비밀번호는 저장소에 적지 않는다.
- 아마노 웹 주소도 저장소에 적지 않고, 데스크 앱 설정에 넣는다.
- 아마노 안내: "출차 5분 전 반드시 등록", "등록된 할인내역은 등록한 사용자만 삭제 가능".
- 아마노 화면 모양이 바뀌면(업데이트) 칸·버튼 이름을 다시 맞춰야 한다. 데스크에 "아마노 화면을 찾지 못함"으로 알려 준다.

## 현장에서 한 번 해야 할 일
1. POS PC에서 아마노 페이지의 칸·버튼 이름 확인 (데스크 앱 설치할 때 함께)
2. 쓰는 할인유형 확정: 지금 화면에는 3·5·15·16·17·18시간. 체험판은 3시간·5시간을 크게, 나머지를 작게 둠

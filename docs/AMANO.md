# 아마노 주차등록 동기화

API는 쓰지 않는다. 아마노코리아 **할인등록 웹 화면**을 데스크 앱이 대신 조작한다.

## 창 배치 (모니터 한 대)
POS 화면 하나에 창을 겹쳐 둔다.

```
맨 앞   입장 데스크 (근무자가 보는 화면)
가운데  POS 프로그램
맨 뒤   아마노 할인등록 웹 (입장 데스크 앱이 열어 둔 창)
```

- 아마노 창은 **입장 데스크 앱이 직접 연다**(Edge로 따로 연 창은 앱이 조작할 수 없음). 모양은 Edge에서 보던 것과 같다.
- 버튼·칸을 화면 좌표가 아니라 **페이지 안의 글자**("검색", "3시간할인", 표 머리 "입차ID · 차량번호" 등)로 찾으므로, 아마노 창이 POS·데스크 뒤에 **가려져 있어도** 입력하고 누른다.

## 아침에 한 번
1. 입장 데스크 앱을 켠다 → 맨 뒤에 아마노 로그인 화면이 열림
2. 처음 한 번만: 운영 설정 → **아마노 · POS** 탭에서
   - 아마노 로그인 주소 (예: `http://아마노주소/login`)
   - 아마노 아이디 · 비밀번호 → **이 PC에만 Windows 암호화로 저장**, 화면에는 다시 보이지 않음
   - POS 프로그램 창 제목 (결제하기 때 앞으로 띄울 창)
3. 그 뒤로는 앱이 **자동 로그인** → **할인등록 화면(`/discount/registration`)으로 자동 이동** → 뒤에 켜 둠
   - 로그인이 풀려도 자동으로 다시 로그인 (실패하면 데스크에 "아마노 로그인이 풀렸어요" + "아마노 화면 보기")

> 아마노 주소·아이디·비밀번호는 저장소와 설치 파일에 넣지 않는다.
> GitHub에 등록한 `amano_ID` · `amano_PW`(GitHub Actions 비밀값)는 자동 빌드 때만 읽을 수 있고, 설치 파일에 넣으면 누구나 꺼낼 수 있어 쓰지 않는다. POS PC에서 한 번 입력하는 방식으로 한다.

## 동작 맞추기
| 데스크에서 | 아마노 화면에서 (자동) | 데스크로 읽어 오는 것 |
|---|---|---|
| 입차일 (기본 전날 — 새벽 손님 때문) · 차량번호 → 검색 | 같은 칸에 입력 → **검색** 버튼 | 조회 목록: 입차ID · 차량번호(건수) · 입차시간 |
| 목록에서 차량 선택 | 같은 줄 클릭 | 차량번호 · 입차시간 · **주차시간** · 할인내역 |
| 할인 버튼 (3시간 · 5시간 · 15시간) | 같은 이름의 **할인유형** 버튼 (확인 창은 자동 확인) | 할인내역: 할인값 · 등록자 · 등록시간 |
| 할인내역 삭제 | 그 줄의 **삭제** 버튼 | 바뀐 할인내역 |

- 누른 뒤 아마노 화면이 새로 열리거나 바뀌는 것을 기다렸다가 다시 읽는다 (최대 8초).
- 아마노 화면에 없는 버튼이면 누르지 않고 이유를 데스크 아래 줄에 보여 준다.

## 글자로 못 찾을 때: 배우기
운영 설정 → 아마노 · POS → **아마노 칸 배우기**(차량번호 칸 · 입차일 칸 · 검색 버튼)
→ 아마노 창이 앞으로 나오고, 그 칸을 한 번 클릭하면 기억한다. 아마노 화면이 바뀌었을 때도 이것으로 다시 맞춘다.

## 코드와 시험
| 파일 | 내용 |
|---|---|
| `apps/desk/src/amano-driver.js` | 아마노 페이지 안에서 칸·버튼 찾기, 입력·클릭, 표 읽기, 로그인, 배우기 |
| `apps/desk/src/amano-sync.js` | 동작 → 화면이 안정될 때까지 기다림 → 결과 읽기 |
| `apps/desk/src/main.js` | 앱: 아마노 창(맨 뒤) · 데스크 창(맨 앞) · 자동 로그인 · POS 창 앞으로 |
| `apps/desk/mock/amano.html` | 캡처를 본뜬 **시험용 가짜 아마노 화면** (시험 계정 test / 1234) |
| `apps/desk/test/*.test.js` | 검색·선택·할인·삭제, 없는 차량, 로그인 풀림, 자동 로그인, 배우기, 데스크↔아마노 연결 |

시험: `cd apps/desk && npm test`

## 남은 일 (현장)
1. 실제 아마노 할인등록 화면 저장 파일(Ctrl+S, 웹 페이지 전체)로 칸·표 이름이 가짜 화면과 같은지 맞추기
2. 할인·삭제 때 확인 창이 뜨는지 확인
3. POS PC에 설치해 검색 → 선택 → 할인을 실제로 한 번 해 보기
